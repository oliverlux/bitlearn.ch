## Auftrag Konzept neues Dokumentationstool
Du arbeitest in der UseOffice AG, welches Software für kleine und mittelständische Unternehmen (KMU) herstellt. Die Softwareentwickler verwalten den Sourcecode mittels der Versionsverwaltung Git und verwenden dazu einen intern gehosteten Gitlab-Server.
Du bekommst von deiner Vorgesetzten den Auftrag, ein neues Dokumentationstool zu evaluieren. Bisher werden Dokumentationen in Word geschrieben und in einem ordnerbasierten Ablagesystem auf Sharepoint abgelegt.
Neu sollen Dokumentationen webbasiert erfasst werden. 

### Fragestellungen
1. Da du dein Konzept ebenfalls mit Word erstellen sollst, beginnst du mit einer Vorlage. Zudem überlegst du dir ein sinnvolles Namenskonzept für deine erstellten Dateien.
2. Wie ist ein Evaluationskonzept aufgebaut? Versuche die Kapitelstruktur in deiner erstellten Vorlage abzubilden.
3. Für eine Evaluation ist es wichtig Anforderungen aufzunehmen. Wie nimmst du diese Anforderungen auf? Wie kategorisierst du diese?
4. Was für webbasierte Dokumentationstools gibt es? Erstelle dazu eine Übersicht.
5. Bei einer Evaluation kommt häufig eine Nutzwertanalyse zum Zug. Wähle drei konkrete Dokumentationstools aus und führe eine Nutzwertanalyse anhand von realistischen Anforderungen durch.
